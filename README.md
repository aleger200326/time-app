# Focus Timer

Браузерный таймер для работы и отдыха в киберпанк-стиле с достижениями и системой рангов. Учебный проект, созданный с помощью Codex на HTML, CSS и JavaScript.

## Возможности

- Режимы «Фокус» (25 минут), «Перерыв» (5 минут), «Глубоко» (45 минут).
- Своя длительность в минутах и секундах.
- Старт, пауза, сброс и круговой индикатор.
- Звуковой сигнал с возможностью отключения.
- Семь ачивок и ранги от E до S.
- Сохранение прогресса в браузере.
- Адаптивный интерфейс для компьютеров и телефонов.

## Инструменты

| Инструмент | Назначение |
| --- | --- |
| HTML5 | Разметка и элементы управления |
| CSS3 | Киберпанк-оформление и адаптивная сетка |
| JavaScript | Отсчёт времени, режимы и достижения |
| JSON и Fetch API | Загрузка данных |
| localStorage | Сохранение прогресса |
| Web Audio API | Звуковой сигнал |
| SVG | Круговой индикатор |
| Google Fonts | Шрифты Orbitron и Rajdhani |
| Codex | Помощь в создании и доработке кода |
| GitHub Pages | Публикация сайта |

Фреймворки и этап сборки отсутствуют. Node.js нужен только для удобного локального сервера. Веб-шрифты загружаются через интернет.

## Структура

```text
time-app/
├── index.html
├── style.css
├── app.js
├── presets.json
├── achievements.json
└── README.md
```

Все файлы должны находиться в одной папке: относительные пути настроены под эту структуру.

## Локальный запуск

1. Установите Node.js с npm.
2. Скачайте репозиторий и откройте терминал в папке с index.html.
3. Запустите сервер:

```bash
npx serve . -l 3000
```

4. Откройте [http://localhost:3000](http://localhost:3000).

Используйте HTTP-сервер: при запуске index.html двойным щелчком браузер может заблокировать загрузку JSON-файлов.

## Публикация на GitHub Pages

Загрузите все файлы в корень репозитория, сохранив имена. В Settings → Pages настройте публикацию из ветки main и папки / (root). После завершения публикации откройте [Focus Timer](https://aleger200326.github.io/time-app/).

## Использование

Выберите режим или задайте минуты и секунды. Нажмите «Старт», чтобы начать отсчёт, «Пауза», чтобы приостановить, или «Сброс», чтобы вернуть заданное время. Завершённые сессии учитываются во вкладке «Ачивки».

Прогресс хранится в текущем браузере на текущем устройстве. Он не синхронизируется между устройствами и удаляется при очистке данных сайта.
